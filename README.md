## Project Description
This is an exploratory data analytics project (no machine learning models) that studies how global
e-waste generation has grown from 2015–2024, how formal recycling has (failed to) keep pace, and which
economic and digital factors best explain per-capita e-waste output across 20 countries and 6 regions.

The project is aligned to two UN Sustainable Development Goals emphasized in this internship's
curriculum:
- **SDG 12** — Responsible Consumption and Production
- **SDG 3** — Good Health and Well-being (informally handled e-waste releases toxic heavy metals)

## Dataset
`global_ewaste_dataset.csv` — a 200-row (20 countries × 10 years) country-year panel with:

| Column | Description |
|---|---|
| Country, Region | Country name and continent/region grouping |
| Year | 2015–2024 |
| Population_Million | Population in millions |
| GDP_per_Capita_USD | GDP per capita (USD) |
| Internet_Penetration_Percent | % of population online |
| EWaste_Generated_kt | Total e-waste generated (kilotonnes) |
| EWaste_per_Capita_kg | E-waste generated per person (kg) |
| EWaste_Formally_Recycled_kt | E-waste formally collected/recycled (kilotonnes) |
| Recycling_Rate_Percent | Formally recycled ÷ generated (%) |

**Data source note:** No live dataset download was reachable from this environment, so the dataset was
**simulated** (`generate_data.py`, seeded for reproducibility) to reflect the real order-of-magnitude
patterns and trends published in the *Global E-waste Monitor* (UNITAR/ITU, globalewaste.org) and
World Bank population/GDP series. Treat absolute figures as illustrative, not official statistics. To
redo this analysis with real official data, download the country-level tables from
[globalewaste.org](https://globalewaste.org) or [Statista](https://www.statista.com) and replace
`global_ewaste_dataset.csv`, keeping the same column names — the notebook will run unchanged.

## Key Findings
- Global e-waste generation grew at roughly a **6% CAGR** (2015–2024), consistently outpacing formal
  recycling growth, widening the "recycling gap" year over year.
- Wealthy, highly digitized countries generate the most e-waste **per person**; populous developing
  economies generate the most **in absolute terms**.
- Countries with the lowest formal recycling rates are disproportionately the same countries with the
  largest, fastest-growing absolute volumes.
- GDP per capita and internet penetration are the strongest correlates of per-capita e-waste generation.
- A simple linear trend projects continued growth through 2027 if current patterns hold.

## Limitations
Simulated dataset (see Data source note above); simple linear trend projection only, no advanced
forecasting model; regional groupings limited to 20 representative countries rather than all ~195.
